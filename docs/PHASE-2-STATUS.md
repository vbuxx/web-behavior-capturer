# Phase 2 Status

Implemented foundations: evidence graph revision/checksum, immutable snapshot service, local stdio MCP, authenticated viewer/provenance UI, annotation sidecar with derived revisions, probe-derived contract revisions, selector fingerprint checkpoints, visual masking, and a 12-fixture evaluation matrix.

The executable evaluator measures WBC extraction/equivalence over three repetitions and reports observer cost/loss. The next scope is a same-agent A/B/C harness plus nested-scroller/boolean-GSAP/open-shadow fixtures before claiming the 80%/20-point target; closed shadow remains deferred to Fase 3.
