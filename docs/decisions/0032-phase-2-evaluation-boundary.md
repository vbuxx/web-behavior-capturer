# ADR 0032 Phase 2 Evaluation Boundary

Status: accepted for Phase 2 foundation
Date: 6 September 2026

## Decision

Keep a 12-fixture capability matrix and an executable three-repetition WBC verifier harness. Report screenshot and trace baselines as unavailable until the same-agent/budget harness is supplied. Separate extraction accuracy, behavior equivalence, agent success, token/time, observer cost, loss, and unsupported coverage.

## Consequence

The evaluation cannot accidentally turn a verifier pass into an agent benchmark claim. Scope is reduced explicitly for nested scrollers, boolean GSAP semantics, closed shadow DOM, and worker-of-worker coverage until dedicated fixtures and adapters exist.
